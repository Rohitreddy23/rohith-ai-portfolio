# Rohith Reddy Chinthala - AI Portfolio Website

A clean one-page portfolio website for showcasing AI/ML engineering experience, projects, skills, and contact links.

## How to Use

Upload these files to a public GitHub repository named:

```text
rohith-ai-portfolio
```

Then enable GitHub Pages:

1. Go to repository Settings.
2. Click Pages.
3. Under Source, select `Deploy from a branch`.
4. Select branch `main`.
5. Select folder `/root`.
6. Save.

Your website will be available at:

```text
https://rohitreddy23.github.io/rohith-ai-portfolio/
```
